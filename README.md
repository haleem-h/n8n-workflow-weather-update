# n8n-workflow-weather-update
Automated weather reporting system built with n8n and OpenWeatherMap API.
🌤 Weather Alert Automation
This workflow runs every morning at 8:00 AM. It fetches data from Kochi via OpenWeatherMap, processes it using JavaScript to make it readable, and sends a custom alert via Email/Message.
